# pi-capture-file

Расширение для [Pi](https://github.com/earendil-works/pi), которое «спасает» файлы скриншотов macOS в момент вставки пути в редактор.

## Проблемы, которые оно решает

1. **Исчезающие файлы drag-and-drop.** Когда перетаскиваешь миниатюру скриншота (плавающее превью macOS) прямо в терминал, терминал вставляет путь вида
   `/var/folders/.../T/TemporaryItems/NSIRD_screencaptureui_<random>/Снимок экрана — ....png`.
   macOS удаляет этот временный файл сразу после завершения перетаскивания — к моменту отправки сообщения файла уже нет.

2. **Неразрывные пробелы в именах скриншотов.** macOS ставит вокруг тире U+00A0 (`Снимок экрана⍽— 2026-11-12 в⍽12.02.05.png`). При копипасте NBSP превращается в обычный пробел, путь перестаёт совпадать с именем файла, и `read` падает с ENOENT.

## Как работает

- Хук `ctx.ui.onTerminalInput` перехватывает **сырой ввод терминала в момент вставки** (до Enter).
- Временные файлы (`/TemporaryItems/`) и файлы с «проблемными» именами **синхронно копируются** в `~/.pi/agent/captured-files/` под ASCII-именем (`screenshot-YYYYMMDD-HHMMSS.png`), путь во вставке подменяется на копию.
- Несуществующий путь ищется в той же папке с нормализацией пробелов (NBSP → обычный) и Unicode (NFC/NFD). Поддерживаются экранированные (`\ `) и сырые пути (Finder → «Copy as Pathname»).
- Фолбэк на событие `input` (отправка сообщения) — для RPC и вставок до загрузки расширения.
- Кэш повторных вставок, лимит размера 500 МБ, автоочистка копий старше 7 дней при старте сессии.
- Если временный файл уже удалён — уведомление «Временный файл уже удалён системой».

## Установка

Вариант 1 — симлинк (глобально, hot-reload через `/reload`):

```bash
ln -s ~/Projects/pi-capture-file/capture-pasted-files.ts ~/.pi/agent/extensions/capture-pasted-files.ts
```

Вариант 2 — путь в `~/.pi/agent/settings.json`:

```json
{ "extensions": ["/Users/<you>/Projects/pi-capture-file"] }
```

Вариант 3 — как Pi-пакет из git:

```bash
pi install git:github.com/<you>/pi-capture-file
```

## Использование

Сделай скриншот (⌘⇧4 / ⌘⇧5) и перетащи плавающую миниатюру прямо в терминал с Pi. В редакторе появится путь `~/.pi/agent/captured-files/...` — файл сохранён и читается напрямую.
